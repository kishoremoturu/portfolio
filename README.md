# Portfolio

A modern React portfolio site for Sai Kishore Moturu, built with Vite and deployed through GitHub Pages.

## Tech Stack

- React 18
- Vite 5
- Tailwind CSS (CDN)
- React Icons

## Getting Started

### Prerequisites

- Node.js 20+
- npm 10+

### Install

npm install

### Run Locally

npm run dev

### Production Build

npm run build

### Preview Production Build

npm run preview

## Project Structure

.github/workflows/ - CI and deployment workflows
src/ - React source code
src/main.jsx - React entry point
src/Portfolio.jsx - main portfolio component
index.html - app shell
vite.config.js - Vite configuration for GitHub Pages

## Deployment

Deployment is handled by GitHub Actions via the workflow in .github/workflows/deploy-pages.yml.

Published URL:
https://kishoremoturu.github.io/portfolio/
